# Actividad 3 - Programación Mobile

## Calculadora Flutter

Este proyecto consiste en una calculadora básica desarrollada en Flutter para la materia de Programación Mobile.

## Funcionalidades

- Suma
- Resta
- Multiplicación
- División
- Borrar un número con `DEL`
- Reiniciar la calculadora con `RESET`
- Mostrar el resultado con `=`
